# Aircraft Flight Data Analyzer

A Python-based project for analyzing aircraft flight data and extracting
flight-performance parameters from telemetry.

## Current Features

- Load flight data from CSV files
- Inspect and validate flight data
- Calculate altitude change
- Calculate climb rate
- Modular Python project structure

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Git / GitHub
